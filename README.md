# Item Slot Reservation（物品格预留）

Don't Starve Together 模组：把储物格固定给指定物品。捡起、制作完成、从装备栏卸下时，物品自动回到那一格；别的物品不会占它。

版本 **0.1.4** · 服务器模组 · 进服玩家需订阅

---

## 它解决什么

物品栏 15 格 + 背包满起来以后，草、树枝、木头、火把到处乱钻，每次都要手动挪。
这个模组让你给某几格「贴条」：这格是草的、那格是树枝的。之后不管怎么捡、怎么做、怎么穿脱装备，东西都自动回位。

---

## 安装

### 房主

创意工坊订阅本模组后，勾选要用的存档：主菜单 **创建世界 → 选槽位 → Mods → 服务器模组** 里勾上它。
（主菜单那个 Mods 界面里的服务器模组页签是只读的，勾不了，必须走存档的模组列表。）

不用工坊的本地安装方式：把 `item-slot-reservation` 整个文件夹放进
`Steam\steamapps\common\Don't Starve Together\mods\`，
最终路径形如 `...\mods\item-slot-reservation\modinfo.lua`，再按上面的方式在存档模组列表里勾选。

### 其他玩家（必需）

`all_clients_require_mod = true`：进服玩家必须订阅本模组。订阅后第一次进房，游戏会自动临时启用并提示重启一次，之后一直有效。
没订阅的玩家进不来（游戏会提示订阅，点一下即自动下载）。

## 操作

| 操作 | 键位 |
|---|---|
| 把已有物品的格子固定给该物品 | 按住 **V** + 鼠标左键点那一格 |
| 取消固定（同一格再点一次） | 按住 **V** + 左键 |
| 清除任意预留 | 按住 **V** + 右键 |
| 预先固定（格子里还没有该物品） | 控制台 `ISR.DebugSetPrefabMark(3, "cutgrass")` |

- 固定键可改：**Mods → Item Slot Reservation → 固定键**（V / B / N / G / 无）。
- 背包里的格子：先打开背包，再按住 V 点背包中的格子。
- 背包里的容器（桶、箱子）也能固定：打开那个容器，按住 V 点它里面的格子即可。容器丢地上就不算了。
- 切斯特、哈奇这类跟着你走的容器同样可以固定；别人的切斯特不行。
- 切斯特没带眼骨（不跟随任何人）时也能固定：打开它、点格子即可，第一次标记的人成为它的主人，之后别人打开也改不了。
- 控制台清标记：`ISR.DebugClearSlotMark(3)`；第二个参数 `true` 表示背包（`ISR.DebugClearSlotMark(2, true)`）。

## 行为细节

| 情况 | 结果 |
|---|---|
| 捡起被预留的物品 | 直接落进预留格，不经过别的格子；固定格里已经有同种未满堆时直接并进去（容器没打开也一样） |
| 捡起没被预留的物品 | 不会占用别人的预留格 |
| 捡起只在容器里固定的物品 | 直接进那个容器（切斯特、背包里的桶），省掉捡起再放回去的一步，并有拾取音效 |
| 容器离你太远 | 不送进去（随身容器除外），按设置里的「容器作用距离」判：近约 2.5 格、中 6 格、远 12 格 |
| 容器固定格与物品栏固定格同时存在 | 容器优先；把设置里的「拾取后放回容器」关掉就只认物品栏的格子 |
| 制作完成 / 从装备栏卸下 | 走同一套逻辑，自动回位 |
| 手动把别的东西拖进预留格 | 能放进去，但该格预留解除（木框消失）——不留死格 |
| 预留格满了再捡同种物品 | 物品掉地上，不硬塞进别的预留格 |
| Shift 快速转移的落点顺序 | 该物品的空预留格 → 物品栏同类未满堆 → 原版给的合法格 → 未预留空格 → 背包 |
| Shift 快速转移，物品栏全部被预留 | 物品落进背包/随身容器；背包也满、或来源就是背包时留在原处 |
| Shift 快速转移时的画面 | 预测按预留标记先算落点，物品栏没位置就直接画进背包，不占别人的预留格、不闪一帧
| 只能放物品栏的东西（以太余烬、沃拓克斯灵魂） | 不受预留限制，直接进物品栏的空格；占用了预留格时该格预留解除 |
| 存档 | 标记存在容器实体上，读档、下地穴（跨 shard）后自动恢复；背包丢地上被捡走，标记跟着背包 |

## 设置项

| 设置 | 说明 |
|---|---|
| 固定键 Pin key | 配合鼠标使用，默认 V |
| 图标透明度 Icon opacity | 空预留格中物品图标的不透明度，默认 35% |
| 拾取后放回容器 Pickup into containers | 开启（默认）：拾取到的物品直接进容器里的固定格；关闭：只认玩家物品栏的固定格，容器固定格仅保留占位 |
| 容器作用距离 Container range | 世界里的容器离玩家多远还能自动接收物品：近（约 2.5 格）/ 中（6 格，默认）/ 远（12 格）。随身携带的容器不受限制 |
| 调试日志 Debug log | 排查问题时打开，日志打到 `client_log.txt` / `server_log.txt`，标签 `[ItemSlotReservation]` |

---

## 注意

- 与容器扩容、自动整理、Shift 批量转移类模组可能冲突，表现是「物品进错格」而不是崩溃。装之前先单独试。
- 卸载前建议把预留清掉：直接删目录不会崩，但存档里残留的标记数据没人读。
